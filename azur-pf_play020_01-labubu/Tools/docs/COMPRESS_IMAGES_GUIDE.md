## Введение

Инструмент `compress-images.js` предназначен для автоматической оптимизации и сжатия изображений различных форматов. Он позволяет значительно уменьшить размер файлов с умным определением прозрачности и применением оптимальных настроек компрессии.

### Основные возможности:
- 🖼️ Автоматическое сжатие всех изображений в проекте
- 🔍 Умное определение прозрачности изображений
- ⚙️ Гибкая настройка параметров компрессии
- 🎯 Индивидуальные настройки для каждого изображения
- 🔄 Конвертация между форматами (PNG→WebP, JPG→AVIF и др.)
- 📊 Подробная статистика сжатия с экономией места
- 🧹 Автоматическая очистка старых сжатых файлов

## Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск компрессии
```bash
npm run compress-images
```

### Что происходит:
1. Скрипт очищает старые сжатые файлы (если есть оригиналы)
2. Сканирует папку `Images/` и находит все поддерживаемые файлы
3. Пропускает уже сжатые файлы (с суффиксом `_compressed`)
4. Автоматически определяет прозрачность каждого изображения
5. Применяет соответствующие настройки компрессии
6. Сохраняет результат как `{имя}_compressed.{формат}`
7. Показывает детальную статистику экономии места

## Методы компрессии

### 1. Автоматическое определение прозрачности
**Что делает:** Анализирует изображение на наличие альфа-канала и применяет соответствующие настройки.

**Как работает:**
- Проверяет количество каналов (3=RGB, 4=RGBA)
- Анализирует метаданные файла
- Для PNG дополнительно проверяет статистику каналов

**Результат:** Прозрачные изображения получают настройки `transparent`, непрозрачные - `opaque`.

### 2. Умное изменение размера
**Что делает:** Ограничивает размер изображения максимальными значениями без потери пропорций.

**Параметры:**
- `width`/`height`: Максимальные размеры в пикселях
- `fit`: Метод подгонки ("inside", "cover", "contain", "fill", "outside")
- `withoutEnlargement`: Не увеличивать маленькие изображения

**Когда использовать:** Всегда для мобильных устройств и веб-приложений.

### 3. Форматная оптимизация
**Что делает:** Конвертирует изображения в оптимальные форматы.

**Стратегии:**
- PNG → WebP (для прозрачных изображений)
- JPG → WebP/AVIF (для фотографий)
- Сохранение PNG для иконок высокого качества

## Определение прозрачности

### Алгоритм определения

```javascript
// Упрощенная логика
async function hasTransparency(imagePath) {
  const metadata = await sharp(imagePath).metadata();

  // Проверка количества каналов
  if (metadata.channels === 4 || metadata.hasAlpha === true) {
    return true;
  }

  // Дополнительная проверка для PNG
  if (path.extname(imagePath) === '.png') {
    const stats = await sharp(imagePath).stats();
    return stats.channels.length === 4;
  }

  return false;
}
```

### Влияние на обработку

| Тип изображения | Определение | Применяемые настройки |
|----------------|-------------|----------------------|
| **Прозрачное** | 4 канала (RGBA) | `quality.transparent`, `outputFormat.transparent` |
| **Непрозрачное** | 3 канала (RGB) | `quality.opaque`, `outputFormat.opaque` |

### Примеры

```
📊 Type: transparent, Format: webp, Quality: 90  ◄── PNG с альфа-каналом
📊 Type: opaque, Format: webp, Quality: 85       ◄── JPG без прозрачности
```

## Форматы изображений

### Поддерживаемые входные форматы
- **JPEG/JPG** - Фотографии, изображения без прозрачности
- **PNG** - Изображения с прозрачностью, иконки
- **WebP** - Современный формат от Google
- **AVIF** - Новейший формат с лучшим сжатием

### Рекомендации по выходным форматам

#### WebP (Рекомендуется)
```json
"outputFormat": { "opaque": "webp", "transparent": "webp" }
```
**Плюсы:** Отличное сжатие, отличная поддержка (99.31% мобильных браузеров), поддержка прозрачности
**Минусы:** Минимальные ограничения в очень старых браузерах

#### AVIF (Превосходный выбор)
```json
"outputFormat": { "opaque": "avif", "transparent": "avif" }
```
**Плюсы:** Лучшее сжатие на рынке, поддержка (97.81% мобильных браузеров)
**Минусы:** Может быть медленнее в обработке на слабых устройствах

#### PNG (Для иконок)
```json
"outputFormat": "png"
```
**Плюсы:** Без потерь, универсальная поддержка
**Минусы:** Большой размер файлов

#### JPEG (Для совместимости)
```json
"outputFormat": { "opaque": "jpeg" }
```
**Плюсы:** Универсальная поддержка
**Минусы:** Нет поддержки прозрачности

### Сравнение размеров

| Исходный файл     | PNG  | JPEG  | WebP         | AVIF         |
|-------------------|------|-------|--------------|--------------|
| photo.jpg (500KB) | -    | 500KB | 350KB (-30%) | 280KB (-44%) |
| icon.png (50KB)   | 50KB | -     | 35KB (-30%)  | 32KB (-36%)  |

## Решение проблем

### Проблема: Изображения выглядят размытыми
**Решение:** Увеличьте качество сжатия:
```json
"quality": { "opaque": 90, "transparent": 95 }
```

### Проблема: Файлы слишком большие
**Решение:** Уменьшите максимальный размер:
```json
"maxSize": { "width": 1280, "height": 720 }
```

### Проблема: Потеряна прозрачность
**Проверьте:**
1. Формат поддерживает прозрачность (PNG, WebP, AVIF)
2. Исходное изображение действительно имеет альфа-канал

**Решение:**
```json
"outputFormat": { "transparent": "png" }
```

### Проблема: Некоторые файлы увеличились в размере
**Объяснение:** Это нормально для:
- Очень маленьких файлов
- Уже оптимизированных изображений
- При конвертации в PNG

**Решение:** Используйте формат "none" для проблемных файлов:
```json
"custom": {
  "small-icon": {
    "outputFormat": "none"
  }
}
```

### Проблема: Ошибка "Cannot process image"
**Диагностика:**
```bash
# Проверить формат файла
file Images/problematic-image.png

# Проверить размер
ls -la Images/problematic-image.png
```

**Решение:** Убедитесь что файл не поврежден и имеет поддерживаемый формат.

### Проблема: Скрипт пропускает файлы
**Проверьте:**
1. Файл не имеет суффикс `_compressed`
2. Расширение файла в списке поддерживаемых
3. Права доступа к файлу

### Проблема: Слишком медленная обработка
**Оптимизация:**
1. Обрабатывайте только измененные файлы
2. Уменьшите качество для тестирования
3. Исключите очень большие файлы из автоматической обработки
