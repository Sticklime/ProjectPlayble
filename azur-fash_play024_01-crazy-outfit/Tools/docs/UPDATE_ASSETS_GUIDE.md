# Документация update-assets.js

## Обзор

`update-assets.js` - это утилита для автоматического обновления секции Assets (Ресурсы) в файле конфигурации `Settings/default.json`. Инструмент сканирует директории проекта, находит все ресурсы (изображения, 3D-модели, звуки, шрифты) и автоматически обновляет конфигурацию.

## Основные возможности

- 🔍 **Автоматическое обнаружение ресурсов** - сканирует все поддерживаемые типы файлов
- 📁 **Организация по папкам** - каждый тип ресурсов в своей директории
- 🗜️ **Поддержка сжатых файлов** - приоритет отдается файлам с суффиксом `_compressed`
- 💬 **Сохранение комментариев** - использует JSONC парсер для сохранения комментариев
- 🎨 **Автоматическое форматирование** - применяет Prettier для единообразного стиля
- ⚡ **Приоритетные ресурсы** - критически важные ресурсы размещаются первыми

## Использование

### Запуск из командной строки

```bash
npm run update-assets
```

## Структура директорий

Инструмент ожидает следующую структуру папок в проекте:

```
проект/
├── Images/          # Изображения (.jpg, .jpeg, .png)
├── Data/            # 3D-модели (.glb)
├── Sounds/          # Звуковые файлы (.mp3, .wav)
├── Fonts/           # Шрифты (.ttf, .otf)
└── Settings/
    └── default.json # Файл конфигурации
```

## Приоритетные ресурсы

Следующие ресурсы всегда размещаются в начале секции Assets:

- `background-loading` - фон загрузки
- `banner-icon` - иконка баннера
- `banner-star` - звезда баннера
- `close-button` - кнопка закрытия
- `icon` - основная иконка
- `logotype` - логотип

## Особенности работы

### Обработка сжатых файлов

Если существуют два файла:
- `texture.png`
- `texture_compressed.png`

В конфигурацию попадет только сжатая версия с суффиксом `_compressed`.

### Специальная обработка Images.glb

Если в папке `Data` существует файл `Images.glb` (содержащий все изображения как текстуры), то отдельные файлы изображений из папки `Images` будут исключены из конфигурации.

### Сортировка ресурсов

Ресурсы сортируются в следующем порядке:
1. Приоритетные ресурсы (в порядке добавления)
2. Остальные ресурсы по типам: изображения → 3D-модели → звуки → шрифты
3. Внутри каждого типа - по алфавиту

## Пример выходного формата

```json
{
  "Assets": {
    // Приоритетные ресурсы
    "background-loading": {
      "type": "image",
      "url": "Images/background-loading.png"
    },
    "close-button": {
      "type": "image",
      "url": "Images/close-button_compressed.png"
    },

    // Остальные ресурсы
    "character": {
      "type": "glb",
      "url": "Data/character_compressed.glb"
    },
    "click-sound": {
      "type": "sound",
      "url": "Sounds/click-sound.mp3"
    },
    "main-font": {
      "type": "web-font",
      "url": "Fonts/main-font.ttf"
    }
  }
}
```

## Обработка ошибок

Инструмент завершит работу с кодом ошибки в следующих случаях:

1. **Ошибка парсинга JSON** - если `default.json` содержит синтаксические ошибки
2. **Отсутствие секции Assets** - если в конфигурации нет секции "Assets"
3. **Ошибка чтения/записи** - если нет доступа к файлам

## Напоминания

1. **Регулярный запуск** - запускайте инструмент после добавления новых ресурсов
2. **Именование файлов** - используйте понятные имена без специальных символов
3. **Сжатие ресурсов** - добавляйте суффикс `_compressed` к оптимизированным файлам
4. **Резервные копии** - инструмент перезаписывает `default.json`

## Устранение неполадок

### Ресурс не появляется в конфигурации

**Проверьте:**
1. Файл находится в правильной папке
2. Расширение файла поддерживается
3. Имя файла не содержит недопустимых символов
