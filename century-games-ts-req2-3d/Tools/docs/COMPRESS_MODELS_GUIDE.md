## Введение

Инструмент `compress-models.js` предназначен для автоматической оптимизации и сжатия 3D-моделей в формате GLB/GLTF. Он позволяет значительно уменьшить размер файлов без существенной потери визуального качества.

### Основные возможности:
- 🗜️ Автоматическое сжатие всех GLB файлов в проекте
- ⚙️ Гибкая настройка параметров компрессии
- 📍 Извлечение и сохранение якорей (anchor points)
- 🎯 Индивидуальные настройки для каждой модели
- 📊 Множество методов оптимизации

## Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск компрессии
```bash
npm run compress-models
```

### Что происходит:
1. Скрипт сканирует папку `Data/` и находит все `.glb` файлы
2. Пропускает уже сжатые файлы (с суффиксом `_compressed`)
3. Извлекает якоря
4. Применяет настройки компрессии из `Tools/configs/model-compression-config.json`
5. Сохраняет сжатые файлы как `{имя}_compressed.glb`
6. Сохраняет якоря в `App/AutoGenerated/AnchorsController.ts`

## Как это работает

### Процесс обработки

```
Data/
├── model1.glb          ──┐
├── model2.glb          ──┤
└── subfolder/          ──┤
    └── model3.glb      ──┤
              │
              ▼
      npm run compress-models
              │
              ├─── Извлечение якорей
              ├─── Применение оптимизаций
              └─── Сохранение результатов
              │
              ▼
Data/
├── model1.glb
├── model1_compressed.glb ◄── Сжатая версия
├── model2.glb
├── model2_compressed.glb ◄── Сжатая версия
└── subfolder/
    ├── model3.glb
    └── model3_compressed.glb ◄── Сжатая версия

App/AutoGenerated/
└── AnchorsController.ts ◄── Экспортированные якоря
```

### Архитектура скрипта

```javascript
GLBCompressor
├── constructor()           // Инициализация путей и конфигурации
├── loadCompressionConfig() // Загрузка настроек из JSON
├── findUncompressedGLBFiles() // Поиск несжатых файлов
├── createGLTFIO()         // Создание IO для работы с GLTF
├── extractAnchors()       // Извлечение якорей из модели
├── getModelConfig()       // Получение конфигурации для модели
├── applyCompressionTransforms() // Применение оптимизаций
├── processGLBFile()       // Обработка одного файла
├── writeAnchorsFile()     // Запись файла с якорями
└── processAllFiles()      // Главный метод обработки
```

## Конфигурация

### Структура конфигурационного файла

Файл находится в `Tools/configs/model-compression-config.json`:

```json
{
  "default": {
    // Настройки по умолчанию для всех моделей
  },
  "custom": {
    "modelName": {
      // Переопределение настроек для конкретной модели
    }
  }
}
```

### Пример кастомизации

Для модели `character.glb` нужно более высокое качество:

```json
{
  "default": {
    "simplify": {
      "ratio": 0.75,
      "error": 0.01
    }
  },
  "custom": {
    "character": {
      "simplify": {
        "ratio": 0.9,    // Оставить 90% полигонов
        "error": 0.005   // Меньшая допустимая ошибка
      },
      "textureCompress": {
        "size": 512,     // Больший размер текстур
        "quality": 50    // Выше качество
      }
    }
  }
}
```

## Методы компрессии

### 1. Draco компрессия
**Что делает:** Сжимает геометрические данные используя алгоритмы Google Draco.

**Параметры:**
- `method`: "edgebreaker" (лучше сжатие) или "sequential" (быстрее)
- `quantizePosition`: Биты для позиций (10-14)
- `quantizeNormal`: Биты для нормалей (8-10)
- `quantizeTexcoord`: Биты для UV координат (10-12)

**Когда использовать:** Всегда, кроме случаев когда нужна максимальная точность геометрии.

### 2. Simplify (Упрощение геометрии)
**Что делает:** Уменьшает количество полигонов сохраняя форму объекта.

**Параметры:**
- `ratio`: Процент сохраняемых полигонов (0.1-1.0)
- `error`: Максимальная допустимая ошибка (0.001-0.1)

**Когда использовать:** Для высокополигональных моделей, особенно фоновых объектов.

### 3. Texture Compress
**Что делает:** Сжимает и изменяет размер текстур.

**Параметры:**
- `format`: "avif", "webp", "jpeg", "png"
- `size`: Максимальный размер в пикселях
- `quality`: Качество сжатия (1-100)

**Когда использовать:** Всегда для мобильных устройств.

### 4. Instance
**Что делает:** Создает инстансы для повторяющейся геометрии.

**Параметры:**
- `min`: Минимум повторений для создания инстанса

**Когда использовать:** Для сцен с повторяющимися объектами.

### 5. Другие оптимизации

- **Flatten:** Удаляет лишнюю иерархию нод
- **Dedup:** Удаляет дублирующиеся данные
- **Weld:** Объединяет близкие вершины
- **Resample:** Оптимизирует анимации
- **Reorder:** Улучшает производительность GPU
- **Prune:** Удаляет неиспользуемые ресурсы

## Работа с якорями

### Что такое якоря?
Якоря (anchors) - это специальные точки в 3D-модели для привязки интерактивных элементов/логики или других объектов.

### Соглашение об именовании
Все якоря должны начинаться с префикса `ANC_`:
- `ANC_particle_spawn`
- `ANC_hero_spawn_1`
- `ANC_hero_spawn_2`

### Формат экспортированных якорей

```typescript
export class AnchorsController {
  public static readonly modelName = {
    "ANC_point1": {
      position: new Vector3(x, y, z),
      quaternion: new Quaternion(x, y, z, w),
      scale: new Vector3(x, y, z)
    }
  };
}
```

### Использование в приложении

```typescript
import { AnchorsController } from './App/AutoGenerated/AnchorsController';

// Получить якорь по имени
const anchor = AnchorsController.myModel["ANC_point1"];
const position = anchor.position; // Уже объект Vector3
const quaternion = anchor.quaternion; // Уже объект Quaternion
const scale = anchor.scale; // Уже объект Vector3
```

## Рекомендации по оптимизации

### 1. Возможный анализ перед сжатием
```bash
# Проверить размер исходных файлов
du -h Data/*.glb

du -h Data/*_compressed.glb

### 2. Оптимальные настройки по типу контента

#### Главные объекты / Персонажи
```json
{
  "simplify": { "ratio": 0.85, "error": 0.005 },
  "textureCompress": { "size": 512, "quality": 40 },
  "quantizePosition": 12
}
```

#### Фоновые объекты
```json
{
  "simplify": { "ratio": 0.5, "error": 0.02 },
  "textureCompress": { "size": 256, "quality": 20 },
  "quantizePosition": 10
}
```

### 3. Баланс качество/размер

| Настройка | Влияние на размер | Влияние на качество |
|-----------|-------------------|---------------------|
| Draco     | Высокое ⬇️        | Низкое              |
| Simplify  | Высокое ⬇️        | Высокое             |
| Tex. size | Очень высокое ⬇️  | Среднее             |
| Tex. quality | Высокое ⬇️     | Среднее             |

### 4. Тестирование результатов

1. **Визуальная проверка:** Откройте сжатую модель в Three.js
2. **Проверка размера:** Сравните размеры до и после
3. **Производительность:** Протестируйте FPS с новыми моделями
4. **Якоря:** Убедитесь что все якоря на месте

## Решение проблем

### Проблема: Модель выглядит искаженной
**Решение:** Увеличьте параметры квантизации в Draco:
```json
"quantizePosition": 14,
"quantizeNormal": 10
```

### Проблема: Текстуры размытые
**Решение:** Увеличьте размер и качество текстур:
```json
"textureCompress": {
  "size": 1024,
  "quality": 60
}
```

### Проблема: Потеряны детали геометрии
**Решение:** Настройте параметры simplify:
```json
"simplify": {
  "ratio": 0.9,
  "error": 0.001
}
```

### Проблема: Якоря не экспортируются
**Проверьте:**
1. Имена нод начинаются с `ANC_`
2. Трансформации применены корректно

### Проблема: Ошибка при компрессии
**Диагностика:**
```bash
# Вывести файлы с ошибками
npm run compress-models 2>&1 | grep "Failed"
