# AssetKeeperGenerator Guide

## Overview

`AssetKeeperGenerator` generates TypeScript file with type-safe static getters for accessing image and 3D model assets. It reads asset configuration from `Settings/default.json` and creates `App/Generated/AssetKeeper.ts` with strongly typed asset accessors.

## Features

- **Type-safe asset access** - Generated getters return proper Three.js types
- **Automatic TypeScript generation** - Creates TypeScript file with JSDoc comments
- **Error handling** - Throws errors for missing assets
- **Property name sanitization** - Handles special characters in asset names

## Usage

### Command Line

```bash
npm run generate-asset-keeper
```

### Programmatic Usage

```javascript
const AssetKeeperGenerator = require('./AssetKeeperGenerator');
const generator = new AssetKeeperGenerator();
await generator.generate();
```

## How It Works

1. Reads `Settings/default.json` to get asset configuration
2. Processes image and GLB assets from the Assets section
3. Generates TypeScript class with static getters
4. Writes `App/Generated/AssetKeeper.ts`

### Generated Output (AssetKeeper.ts)

```typescript
// Generated by Tools/AssetKeeperGenerator/AssetKeeperGenerator.js
// Do not edit manually - this file is regenerated automatically

import { Texture } from "three";
import { GLTF } from "three/examples/jsm/loaders/GLTFLoader";

declare const App: {
  ThreeAssets: {
    [key: string]: any;
  };
};

/**
 * AssetKeeper provides type-safe access to project assets
 */
export class AssetKeeper {
  /**
   * Gets asset by key
   * @param key Asset key to retrieve
   * @returns The requested asset
   * @throws Error if asset is not found
   */
  public static getAsset(key: string): any {
    const asset = App.ThreeAssets[key];

    if (!asset) {
      throw new Error(`Asset not found: ${key}`);
    }

    return asset;
  }

  // === IMAGE ASSETS ===

  /**
   * Get image asset: background
   * @returns Texture object
   */
  public static get background(): Texture {
    return this.getAsset("background") as Texture;
  }

  /**
   * Get image asset: ui-button
   * @returns Texture object
   */
  public static get ["ui-button"](): Texture {
    return this.getAsset("ui-button") as Texture;
  }

  // === 3D MODEL ASSETS ===

  /**
   * Get 3D model asset: character
   * @returns GLTF object
   */
  public static get character(): GLTF {
    return this.getAsset("character") as GLTF;
  }
}
```

## Asset Types

### Supported Asset Types

- **image** - Generates getters returning `Texture` objects
- **glb** - Generates getters returning `GLTF` objects
- **sound**, **web-font** - Ignored (not processed)

### Property Name Handling

Asset names are converted to valid TypeScript property names:

- **Valid identifiers** - Used as-is: `background`, `character`, `icon`
- **Invalid identifiers** - Wrapped in brackets: `["ui-button"]`, `["close-icon"]`

## Usage in Code

After generation, use AssetKeeper in your application:

```typescript
import { AssetKeeper } from "Generated/AssetKeeper";

// Get image texture
const backgroundTexture = AssetKeeper.background;
material.map = backgroundTexture;

// Get 3D model
const characterModel = AssetKeeper.character;
scene.add(characterModel.scene);

// Access assets with special characters
const buttonTexture = AssetKeeper["ui-button"];
```

## Error Handling

AssetKeeper throws errors for missing assets:

```typescript
try {
  const texture = AssetKeeper.missingAsset;
} catch (error) {
  console.error(error.message); // "Asset not found: missingAsset"
}
```

## Integration with Build Process

AssetKeeperGenerator is typically run after:

1. **AssetEnumerator** updates `Settings/default.json`
2. Assets are loaded by the main application
3. Before TypeScript compilation

## Troubleshooting

### Generator fails with "Settings file not found"
- Ensure `Settings/default.json` exists in project root
- Check that the generator is run from correct directory

### Generated file has compilation errors
- Verify asset names in `Settings/default.json` are valid
- Check that all referenced assets exist

### Assets return undefined at runtime
- Ensure assets are loaded before accessing through AssetKeeper
- Verify asset keys match exactly between config and usage

### Property name conflicts
- Asset names with special characters use bracket notation
- Use `AssetKeeper["asset-name"]` for names with hyphens/spaces
